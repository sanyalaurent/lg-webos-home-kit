# Быстрая оболочка Luma для LG webOS

Luma — отдельное нативное приложение с избранными приложениями и HDMI. Здесь закреплён **экспериментальный PR88, Luma 2.10.2**, использованный для проверки раннего Home на webOS 5. Это не CleanYourTV и не обещание ускорить декодирование видео или сеть. Запуск отдельным приложением — рекомендуемый первый шаг.

Нужны совместимый телевизор LG с ARM32 webOS, уже полученный root и **elevated Homebrew Channel**. Установка IPK через Developer Mode сама по себе не даёт root и доступ к системному Home; одного пользователя `prisoner` для описанной интеграции недостаточно. Способы получения root этот инструмент не выполняет. Совместимость запуска и замены Home различается по прошивкам; upstream указывает webOS 4+ для запуска, но не гарантирует takeover на всех моделях.

Скрипты в этой папке — собственная интеграция. Исходники и бинарники Luma не включены; Luma распространяется upstream под MIT. Устройства при подготовке репозитория не изменялись. Локальные тесты не доказывают совместимость вашего ТВ.

## 1. Получить проверенный пакет

Требуются Python 3.9+, настроенный `gh` для загрузки GitHub Actions artifact и уже установленный официальный `@webos-tools/cli` для установки. `fetch` не исполняет содержимое пакета. Артефакт может со временем истечь; тогда команда завершится ошибкой — она не подменяет пакет на `latest`.

Из корня репозитория:

```sh
python3 tv/launcher/luma.py fetch --output "$HOME/Downloads/com.ecklf.luma_2.10.2_arm.ipk"
```

Если официальный ZIP уже скачан со страницы сборки:

```sh
python3 tv/launcher/luma.py fetch --artifact-file /path/to/official-artifact.zip --output /path/outside/repository/luma.ipk
```

## 2. Установить отдельное приложение

`TV_DEVICE` — имя устройства, которое вы самостоятельно настроили в webOS CLI. Просмотрите план, затем добавьте `--apply`:

```sh
python3 tv/launcher/luma.py install --device TV_DEVICE --ipk /path/to/luma.ipk
python3 tv/launcher/luma.py install --device TV_DEVICE --ipk /path/to/luma.ipk --apply
```

Это первая установка `com.ecklf.luma` через `ares-install`. Перед `--apply` скрипт делает read-only `ares-install --list` и **отказывает, если Luma уже установлен**. Обновление и понижение версии не автоматизированы. Если Luma уже служит Home, сначала отдельно отключите takeover и проверьте возврат штатного Home; затем сохраните настройки приватно и следуйте инструкции обновления upstream. Обновлять активный Home-binary обычной установкой нельзя. Скрипт не выгружает профили с телевизора; результат inventory используется только для проверки ID. Установка **не** включает автозапуск, замену LG Home, привязку кнопок, изменения preload или системных служб.

Откройте Luma с пульта. Проверьте картинку, стрелки/OK/Back, запуск выбранного приложения, HDMI, возврат в LG Home, сохранение настройки после закрытия и повторного открытия. Для отмены удалите отдельное приложение через обычный интерфейс ТВ. Если takeover когда-либо включался, сначала отключите его: простое удаление приложения оставляет ранние hooks.

## 3. Профиль интерфейса

[profile.json](profile.json) — публичный шаблон совместимых настроек, **не дамп телевизора и не автоматический импорт**. Копию храните вне Git. Проверка полностью локальная:

```sh
python3 tv/launcher/luma.py profile --output /path/outside/repository/my-luma-profile.json
python3 tv/launcher/luma.py profile --file /path/outside/repository/my-luma-profile.json
```

Перенесите выбранные значения через настройки Luma с пульта. Это сохраняет правильного владельца файла и выбор хранилища самой программой. Скрипт намеренно не выбирает один из нескольких `preferences.json` и не перезаписывает его через root: на разных установках приоритет хранилищ отличается.

| Настройка Luma | Значение шаблона / действие |
| --- | --- |
| Interface → Language | Выберите свой язык; `language` в шаблоне `en`, для русского `ru` |
| Reduced motion | Включено: меньше анимаций; это не измеренный прирост производительности всех приложений |
| Weather → Show widget | Выключено; координат и имени в шаблоне нет |
| Clock | 24 часа, секунды выключены |
| Home captions / Apps captions | Имена скрыты на Home, видны в списке Apps |
| Favorites | Начальный список пустой; добавьте нужные приложения через меню Apps и расставьте их в Home |
| Inputs | Выберите для каждого обнаруженного входа Auto, On или Off; On показывает плитку даже без кабеля |
| Input names | По желанию задайте имя в UI; шаблон пустой |
| Background / Text rendering | `slate` / штатное `msaa`; переключение rendering требует перезапуска Luma |

`favorites` и `hidden` содержат **реальные ID установленных приложений**, а `input_modes`/`input_names` — ID обнаруженных входов, не предполагаемый номер разъёма. Программа не угадывает ID или набор HDMI. Пустое `input_modes` оставляет upstream Auto: подключённые входы могут появляться автоматически. Шаблон не скрывает и не удаляет приложения; скрытие плитки не освобождает память приложения.

Упрощение Home, отключение погоды и сокращение избранного уменьшают визуальную нагрузку. Quick Start+ может ускорять тёплое пробуждение ценой ожидания с сохранённым состоянием; оно не устраняет время холодной загрузки после обесточивания. Не отключайте системный Home, `qml-runner`, аудио/HDMI, сетевые службы и preload массовым debloat-скриптом. Отключение preload отдельного редко используемого приложения способно освободить память, но замедляет его первый запуск и требует отдельной диагностики данной прошивки.

## 4. Сделать Luma системным Home

Это отдельная root-интеграция с boot hooks и ранним сервисом. В комплекте есть только [read-only doctor и экспериментальный план](EXPERIMENTAL-HOME.md). Универсального `--apply` для Home здесь нет: загрузочная цепочка, ABI, конфликты hooks и возможность отката должны быть проверены на конкретном ТВ. Физические файлы LG Home должны сохраняться.

Источники закреплённой версии: [README](https://github.com/ecklf/lg-luma/blob/dd398595bed8ea1fc2827f9f47a0a38a0779681b/readme.md), [настройки](https://github.com/ecklf/lg-luma/blob/dd398595bed8ea1fc2827f9f47a0a38a0779681b/src/model.rs), [выбор хранилища](https://github.com/ecklf/lg-luma/blob/dd398595bed8ea1fc2827f9f47a0a38a0779681b/src/storage.rs), [Home integration](https://github.com/ecklf/lg-luma/blob/dd398595bed8ea1fc2827f9f47a0a38a0779681b/tv/home.cjs).
