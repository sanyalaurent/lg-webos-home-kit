# YouTube AdFree для rooted webOS

Этот компонент устанавливает официальный upstream **RF1705 YouTube Cobalt AdFree 2.0.6-beta** как замену payload существующего нативного YouTube. SAM metadata и ID `youtube.leanback.v4` сохраняются: второй значок не создаётся. Это собственные интеграционные скрипты, не форк движка. Код и бинарные файлы upstream в этой репозитории не распространяются.

Нужны уже настроенные **root SSH**, Python 3.9+ и OpenSSH на компьютере, стандартные `sh`, `tar`, `sha256sum`, `od`, `stat`, `readlink` на ТВ. Проверяются ELF32 little-endian ARM исходного runtime и наличие `/lib/ld-linux.so.3` в системе и jail; другое или неизвестное ABI отклоняется. Получение root и exploits здесь не реализуются. VPN не используется.

Поддерживается уже writable постоянный каталог оригинального LG native-приложения с `main=cobalt`, включая проверяемый LG overlay: `upperdir` совпадает с app directory, `lowerdir` и `workdir` имеют ожидаемую платформенную структуру и backing storage является постоянным writable filesystem. Временные bind mounts, stacked/неизвестные mounts, read-only squashfs, временные файловые системы, неизвестный runtime UID и неоднозначные каталоги отклоняются. Скрипт не перемонтирует rootfs, не редактирует образы и не меняет системные права. Сначала проверяйте `doctor`.

## Диагностика

Замените `root@TV_HOST` своим существующим SSH target. Ключ ТВ должен уже присутствовать в `known_hosts`: проверка ключа не отключается. Откройте штатный YouTube, чтобы диагностика прочитала UID/GID именно его процесса; содержимое профиля не читается.

```sh
python3 tv/youtube_tv.py doctor --host root@TV_HOST
```

Если обнаружено несколько каталогов, передайте `--app-dir` с одним из показанных системных путей. `doctor` ничего не меняет, не запускает приложение и не создаёт резервных копий.

## Скачать и проверить пакет

Каталог staging должен находиться **вне git-репозитория**. Это исключает случайную публикацию upstream бинарника.

```sh
tv_stage=$(mktemp -d "${TMPDIR:-/tmp}/youtube-kit.XXXXXX")
python3 tv/youtube_tv.py fetch --stage-dir "$tv_stage"
```

Источник: [официальный RF1705 release](https://github.com/RF1705/youtube-webos-cobalt-adfree/releases/tag/v2.0.6-beta).

Зафиксированы SHA-256:

```text
IPK:    b04aefc057d0bac230ee69388e31f48dd170ea000b7245ed549a259fde2bc86c
Cobalt: 15c0e77d0315a0a1ae2661100738aa191504e1f7a0ff14e2225e6553264a72a2
```

Архив проверяется до извлечения; links, traversal и специальные файлы запрещены. Перед установкой содержимое извлекается заново из проверенного IPK. Код пакета на компьютере не выполняется.

## Установка

Во время операции не открывайте YouTube с пульта или телефона. Скрипт завершит только процесс выбранного приложения через TERM и прервётся, если тот не остановится; force kill не используется.

```sh
python3 tv/youtube_tv.py install --host root@TV_HOST --stage-dir "$tv_stage" --apply
```

Установка требует явного `--apply`. До замены создаётся **на самом ТВ** root-only backup `cobalt`, `content`, `lib` с SHA-256; каталог backup имеет режим 0700, файлы — 0600. Это копия payload **до данной установки**: LG metadata не доказывают, что владелец прежде никогда не менял бинарник вручную. Если исходный клиент хранит аккаунт или cookies внутри `content`, эти данные также входят в приватный локальный backup. Он не выгружается с ТВ и не публикуется. Авторизация между профилями не переносится. Для RF создаётся отдельный закрытый HOME внутри app directory; его UID/GID выводятся из работающего исходного процесса, не зашиты в код. В RF нужно войти самостоятельно.

Native launcher wrapper запускает соседний `cobalt.real`, сохраняя каталог ресурсов, библиотеки и SAM arguments. Приложение автоматически не запускается: откройте его самостоятельно и проверьте результат. Отсутствие `/bin/sh` в app jail либо несовместимость shell entrypoint выявляется первым запуском; в таком случае используйте rollback.

`--disable-av1` — необязательный экспериментальный флаг. Он передаёт поддерживаемый этим runtime аргумент `--disable_media_codecs=av01`. По умолчанию AV1 **не отключается**: переход на VP9 способен вызвать зависания или падения preview на некоторых моделях. Этот флаг и shared A/V mode 0 не являются универсальными исправлениями. Скрытые codec/backend параметры глобально не меняются.

## Проверка и откат

Beta не гарантирует 4K, HDR, 60 FPS или стабильность на любой модели. Проверьте несколько запусков из Home, превью, звук и синхрон, длинный ролик, pause/resume и перемотку. Для качества проверяйте **Current Res** в Stats for nerds, фактический codec и HDR-индикатор ТВ; первоначальное native `3840×2160` или заданный максимум `60` не доказывают стабильное 4K60. При зависании или crash не оставляйте такой вариант основным.

```sh
python3 tv/youtube_tv.py rollback --host root@TV_HOST --apply
```

Rollback сверяет hash backup и неизменность SAM metadata/launcher, останавливает только приложение и восстанавливает исходный payload с правами из tar. Исходный профиль вне заменяемых каталогов остаётся на месте; профиль внутри `content` восстанавливается из приватного backup. Отдельный профиль RF также остаётся приватно на ТВ, чтобы не удалять данные аккаунта без отдельного решения. Повторный rollback без активной установки безопасен.

Backup сохраняется в `/var/lib/youtube-kit/backups/` **на ТВ**. До первого удаления payload записывается и сбрасывается на диск журнал `PENDING`; он используется и при самом rollback. Поэтому повторный rollback может восстановить частично заменённое приложение даже с отсутствующим launcher. После потери SSH/питания повторите команду rollback; не удаляйте backup/journal вручную. Устаревший lock снимается только при смене boot ID либо завершившемся процессе владельца; активный или неоднозначный lock требует проверки. При изменившихся metadata после обновления LG восстановление также требует ручной оценки.

LG видит исходную SAM version: обновление приложения может заменить интеграцию. Скрипт не блокирует обновления всего телевизора и не устанавливает автопереустановку. Повторный запуск после перезагрузки и после обновлений входит в проверку владельца.

Диагностические отчёты, любые screenshots, журналы, hostnames, backup и профили **не добавляйте в публичный git**. Инструмент не делает снимков экрана и не выводит auth storage или полный журнал Cobalt.
