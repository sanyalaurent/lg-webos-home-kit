# Настройки LG: сначала предварительный план

Это отдельный необязательный модуль для LG webOS с **уже имеющимся root SSH и Node.js 8+ на ТВ**.
Обычный Developer Mode не предоставляет этих системных прав. Модуль не устанавливает root,
оболочку, загрузочные hooks или фоновые службы. По умолчанию он только читает настройки.
Доступность внутренних API зависит от модели, региона и прошивки: эти API не являются
стабильным публичным контрактом LG. Отсутствующее поле, иной тип и отказ доступа означают
`unsupported_or_unknown`; скрипт не создаёт неизвестные настройки.

Ниже только примеры выбора функций, без чьих-либо сохранённых настроек. Скорость Home,
свободная RAM и качество изображения не измеряются и не обещаются. Отдельную оболочку
выбирайте по [руководствам родительского проекта](../README.md).

## Предварительный план и применение

Запускайте с компьютера из корня репозитория. Используется существующее SSH-подключение;
проверка known_hosts обязательна. Пароли, IP и ключи в профилях не сохраняются.

```sh
python3 tv/settings/settings.py doctor --host root@TV_HOST
python3 tv/settings/settings.py plan --host root@TV_HOST --profile privacy
# Только после проверки плана и решения владельца:
python3 tv/settings/settings.py apply --host root@TV_HOST --profile privacy --apply
```

`privacy` запрашивает только следующие существующие строковые поля `on`/`off`:

| Выбор | Категория / поле | Желаемое значение |
|---|---|---|
| Live Plus / ACR | `option.livePlus` | `off` |
| Live Promotion | `option.livePromotion` | `off` |
| Ограничение рекламного отслеживания | `general.lmt` | `on` |
| Дальняя голосовая активация | `general.voiceLongDistance` | `off` |

Это **не полный отзыв согласий** и не аппаратное выключение микрофона. Наличие
`voiceLongDistance` не доказывает наличие встроенного микрофона. Для голосовой кнопки
пульта, обязательных соглашений и региональных согласий используйте меню ниже.
Запуск отдельных служб не используется как доказательство записи или отсутствия телеметрии.

Ответ различает `applied_verified`, `partial_verified`, `unsupported_or_unknown` и ошибки.
При частичном применении код возврата ненулевой: это не полный успех. Проверяются
`returnValue` каждого Luna-ответа и повторное чтение каждого записанного поля.
API может принять запись, но конкретная функция всё равно требует проверки на ТВ.

## Предзагрузка только неиспользуемых приложений

Сначала откройте [profiles/unused-preloads.json](profiles/unused-preloads.json) и добавьте
в пустой `settings` только нужные вам ID из `available_settings`:
`browser-preload-off` и/или `netflix-preload-off`. Пока список пуст, записей не будет.
Это отдельный opt-in пример: браузер и Netflix не считаются
ненужными для каждого владельца. Для частого использования предзагрузку можно сохранить.

```sh
python3 tv/settings/settings.py plan --host root@TV_HOST --profile unused-preloads
python3 tv/settings/settings.py apply --host root@TV_HOST --profile unused-preloads --apply
```

Меняется только `isEnabled` у единственной существующей записи выбранного приложения
в `com.webos.service.preloadmanager.supportAppList` через configd. Полный список читается
перед записью; все остальные поля/приложения сохраняются и проверяются повторным чтением.
Home, YouTube и входы не входят в этот профиль. Неизвестная/дублированная запись пропускается.

Это **только постоянная конфигурация**, без `setPreloadPolicy`, завершения процессов или
автоматической перезагрузки. Уже загруженное приложение может оставаться в памяти.
В удобное время самостоятельно выполните обычный перезапуск/включение и проверьте результат;
немедленное освобождение RAM, ускорение загрузки и сохранение политики после обновления
прошивки не гарантируются. Отказ от preload может замедлить запуск выбранного приложения.

## Приватный backup и откат

До первой записи изменяемых поддерживаемых значений создаётся root-only JSON на самом ТВ:
`/var/lib/lg-settings-kit/`, каталог 0700, файлы 0600. В нём только ID выбранных настроек
и их значения до/после; аккаунты, cookies, EULA документы и полный config не экспортируются.
Backup/journal сбрасывается на диск перед изменением. Профили не содержат исходные значения
конкретного владельца. `doctor` показывает ID приватных журналов для восстановления после обрыва.

```sh
python3 tv/settings/settings.py rollback --host root@TV_HOST --backup-id BACKUP_ID_FROM_APPLY --apply
```

Откат читает приватную копию **на выбранном ТВ**, возвращает только затронутые значения
и проверяет их. Более позднее отличающееся значение не перезаписывается: выводится конфликт.
Незавершённый журнал требует восстановления перед следующим применением. Ошибки обычного
применения вызывают попытку отката; обрыв SSH/питания требует повторной диагностики и
отката по ID журнала. Не удаляйте journal/lock вручную без оценки состояния. Параллельные
операции блокируются; неоднозначный или пустой lock после аварии требует ручной проверки:
сначала подтвердите отсутствие выполняющейся операции, сохранность журнала и путь восстановления,
не удаляйте lock при возможной параллельной установке. JSON backup не публикуйте.
Постоянство `/var/lib` на конкретной прошивке нужно подтвердить до использования после reboot.

## Штатные меню: Quick Start+, реклама и согласия

- **Quick Start+ / Q Start+** — включайте, если нужен быстрый выход из standby. Это не ускоряет
  полный cold boot и сохраняет больше состояния/памяти. При нехватке памяти LG также рекомендует
  отключение Quick Start+ как диагностический шаг. На webOS 4.5/5 путь обычно
  All Settings → General → Additional Settings → Q Start+; в новых версиях путь меняется.
  Проверенного универсального ключа записи здесь нет; скрипт эту функцию не меняет.
- **Home Auto Launch / Power On Screen** выбирает начальный экран. Он не заменяет оболочку
  и не является общим исправлением задержки холодной загрузки. Не меняйте скрытые bootd,
  snapshot, CEC или power hooks по совету для другой модели.
- **Live Plus** выключите в General / Additional Settings, если не нужно распознавание контента.
  **Live Promotion / Home Promotion / Content Recommendation** выключайте, если эти пункты есть
  и рекомендации не нужны. Названия и расположение зависят от года и региона.
- **User Agreements**: снимите только необязательные согласия Viewing Information / ACR,
  Voice Information, Interest-Based / Cross-Device Advertising и Marketing, если не пользуетесь
  этими функциями. Не используйте Select All. Сохраните обязательные Terms of Use и Privacy Policy;
  неизвестные документы не переключайте автоматически. На новых ТВ раздел обычно расположен
  в Support → Privacy & Terms; на старых — General → About This TV → User Agreements.
- В Advertisement включите **Limit AD Tracking**, если этот пункт доступен. Это не удаление
  всей рекламы и не настройка YouTube AdFree. После обновлений и смены региона проверьте меню снова.
- При отказе от Voice Information голосовой поиск может перестать работать. Аппаратный выключатель
  микрофона есть только у некоторых моделей; не удаляйте драйверы микрофона/камеры.

Обязательные согласия, `generalTermsAllowed`, `networkAllowed`, `chpAllowed` и Select-All flags
никогда не входят в авто-профили. Региональная схема EULA различается; прямое копирование
чужого `eulaStatus`/`eulaInfoNetwork` здесь не применяется. Не добавлены hosts/DNS blocklists,
systemd stop/mask, удаление LG Home, picture/render/GPU tweaks или отключение основных LG служб.

Первичные источники: [LG: меню начального экрана и Quick Start+](https://www.lg.com/us/support/help-library/lg-tv-how-to-set-the-default-input--20153711388714),
[LG: диагностика нехватки памяти](https://www.lg.com/uk/support/product-support/troubleshoot/help-library/cs-CT00008333-20154522128518/),
[LG: ACR, голос и добровольные согласия](https://www.lg.com/us/newsroom/corporate/statement-understanding-privacy-on-lg-smart-tvs).
Внутренние ключи сверялись с фактическими чтением/записью и повторным чтением settingsservice/configd
в ограниченном испытании. Это основание для предварительного плана, а не сертификация всех LG моделей.
