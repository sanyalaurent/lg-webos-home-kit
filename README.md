# LG webOS Home Kit

**Передайте эту репу и модель LG/роутера нейросети — начните с [готового запроса](docs/AI_SETUP.md).**

Инструкции и инструменты для быстрой оболочки LG, приватности, YouTube с блокировкой рекламы
и обхода DPI на роутере. Компоненты выбираются отдельно после проверки модели и прошивки:

| Компонент | Задача | Готовая автоматизация |
|---|---|---|
| [Developer Mode LG](docs/LG_DEVELOPER_MODE.md) | Официальный режим разработчика, Node.js/webOS CLI, подключение как `prisoner` | Пошаговая инструкция LG; это не root |
| [Root LG](docs/LG_ROOT.md) | Подбор способа по модели и прошивке, Homebrew Channel, проверка постоянства доступа | Руководство по upstream; универсального auto-root нет |
| [Быстрая оболочка Luma](tv/launcher/README.md) | Native launcher, избранные приложения/HDMI, сокращённые анимации; экспериментальная замена Home | Проверка пакета и профиль; takeover требует отдельной проверки |
| [Настройки LG](tv/settings/README.md) | Реклама/ACR, голосовые параметры, необязательная предзагрузка приложений | План, поддерживаемые поля, приватная копия и откат |
| [Роутер](router/README.md) | zapret2 для обхода DPI на выбранных устройствах; несколько стратегий и необязательная автопроверка | Совместимый OpenWrt с fw4/nftables, root SSH и NFQUEUE |
| [Телевизор](tv/README.md) | Альтернативный клиент YouTube с блокировкой рекламы, резервной копией и откатом | Поддерживаемый ARM32 LG webOS с уже имеющимся root SSH |

Роутер отвечает за доступ к YouTube, клиент на телевизоре — за фильтрацию рекламы.
Они устанавливаются отдельно. Работу видео нужно проверить на самом устройстве:
успешный HTTPS-запрос не доказывает воспроизведение или скорость 4K.

## С чего начать на LG

1. Узнайте точную модель, версию webOS и **версию ПО/firmware**; это разные значения.
2. Для официальной разработки используйте [Developer Mode](docs/LG_DEVELOPER_MODE.md).
   Для Luma Home, расширенных настроек и замены YouTube нужен уже полученный root.
3. Если root ещё нет, пройдите [проверку подходящего метода](docs/LG_ROOT.md).
   Root и Developer Mode — отдельные пути; эксплойт может не требовать Developer Mode.
   На уже rooted ТВ не устанавливайте Developer Mode заново без проверки совместимости с Homebrew Channel.
4. Проверьте Luma как отдельное приложение. Затем настройте приложения/HDMI в личном профиле.
   Замена кнопки Home и ранний старт — отдельный эксперимент, с сохранением LG Home и готовым возвратом.
5. Выберите поддерживаемые [настройки приватности/предзагрузки](tv/settings/README.md).
   Quick Start+, пользовательские соглашения и фоновые службы описаны в [примечаниях](docs/LG_TUNING.md).

Меню, HDMI-номер, регион, согласия и режим питания не переносятся с чужого телевизора.
Профили в репе универсальные; заполненные значения остаются у владельца.

## Подойдёт ли мой роутер?

Начать проверку можно **с любой модели**. Готового установщика для любой прошивки не существует.
Нужны точная модель, аппаратная ревизия и текущая прошивка. Один и тот же корпус
может содержать разные чипы и иметь разные способы восстановления.

- Уже установлен OpenWrt с fw4: переходите к диагностике [модуля роутера](router/README.md).
- Другая Linux-прошивка с root: проверяются ядро, NFQUEUE, архитектура, автозапуск и offload;
  возможна отдельная интеграция по документации upstream.
- Штатная закрытая прошивка или неизвестная модель: сначала проверка производителя и
  точной записи OpenWrt. Возможные варианты — поддерживаемая прошивка, отдельный Linux-шлюз
  или решение на конечном устройстве. Сам факт наличия SSH/Entware не доказывает совместимость.

Подробная [матрица решений](docs/COMPATIBILITY.md) и [инструкция для нейросети](docs/AI_SETUP.md)
не разрешают автоматически прошивать устройство или переносить образ соседней модели.

Можно подготовить локальную анкету без подключения к роутеру:

```sh
python3 tools/assess_router.py --model "ТОЧНАЯ МОДЕЛЬ" --revision "РЕВИЗИЯ" --firmware "ТЕКУЩАЯ ПРОШИВКА"
```

Скопируйте вывод в нейросеть вместе со ссылкой на репозиторий. Этот инструмент
**не содержит базы совместимых моделей** и не заменяет проверку первичных источников.

## Оригинальные проекты

- [bol-van/zapret](https://github.com/bol-van/zapret) — оригинальный проект и документация по платформам.
- [bol-van/zapret2](https://github.com/bol-van/zapret2) — движок, на который рассчитаны скрипты OpenWrt в этой репе.
- [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) — вариант для Windows.
- [RF1705/YouTube webOS Cobalt AdFree](https://github.com/RF1705/youtube-webos-cobalt-adfree) — клиент для LG webOS.
- [ecklf/lg-luma](https://github.com/ecklf/lg-luma) — быстрая native-оболочка.
- [webOS Brew](https://www.webosbrew.org/) — Homebrew Channel и сведения о root.

Upstream скачивается отдельно с проверкой закреплённого хеша. Бинарников,
прошивок LG, пользовательских профилей и экспортов домашней сети в репозитории нет.
Лицензии и авторство перечислены в [THIRD_PARTY.md](THIRD_PARTY.md).

## Порядок настройки

1. Заполните [запрос для нейросети](docs/AI_SETUP.md) и получите заключение по своей модели.
2. Выполните read-only диагностику соответствующего модуля. Для LG начните с раздела выше; для роутера — с его модуля.
3. Подготовьте резервную копию и способ восстановления. Первую установку zapret2 выполните по upstream;
   затем настройте область применения и стратегии через модуль роутера.
4. Сначала проверьте доступ к YouTube. При необходимости отдельно установите клиент LG и войдите в аккаунт на ТВ.
5. Проверьте обычный запуск, несколько видео, звук, перемотку и нужное качество.

Команды изменения конфигурации требуют явного `--apply`; примеры адресов из TEST-NET
нужно заменить своими значениями в **локальном** файле. Настройки по умолчанию не включают обход для всей сети.

## Границы

- Это набор интеграционных инструментов. Установка на произвольной модели и прошивке не испытана.
- Стратегии DPI зависят от провайдера и могут перестать работать. Проверка watchdog ограничена сетевыми endpoint;
  автопереключение не означает проверку рекламы, QUIC, каждого CDN или видеосегментов.
- zapret не меняет внешний IP и не решает ограничения по стране аккаунта или IP сам по себе.
- Обычный DNS-блокировщик не обеспечивает удаление рекламных роликов YouTube на общих видеодоменах.
- RF `2.0.6-beta` может зависать и вылетать; стабильные 4K/HDR/60 FPS после нового запуска не гарантируются.
  Постоянное отключение AV1 не включено как универсальное исправление.
- Root/прошивка не запускаются автоматически. Для LG есть руководство по выбору и выполнению подходящего upstream-метода.
  Официальный Developer Mode не даёт прав для TV-инсталлятора AdFree, замены Home или расширенной настройки.
- Возможность запустить Luma не доказывает возможность заменить Home. Пакет PR/CI экспериментальный,
  artifact может истечь; хеши и поддержку нельзя молча заменять на `latest`.

## Разработка и публикация

```sh
make check
```

Проверяются приватные данные, shell-синтаксис и тесты логики. Эти проверки не являются
приёмкой на реальном роутере/телевизоре. Локальные параметры храните в `.local/`,
а загрузки — во внешнем staging-каталоге, указанном документацией модуля.
Перед публикацией диагностики следуйте [SECURITY.md](SECURITY.md).
Для полного набора локальных проверок нужны Python 3.9+, POSIX `sh` и Node.js;
проверки не подключаются к устройствам и не запускают root-методы.
