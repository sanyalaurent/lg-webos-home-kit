# Дайте эту инструкцию нейросети вместе с моделью LG и/или роутера

Скопируйте запрос ниже и добавьте ссылку на этот репозиторий либо приложите его ZIP.
Пароли, ключи Wi-Fi, серийные номера, MAC, cookie и резервные копии прикладывать не нужно.
Если нейросеть не умеет открывать ссылки, приложите README, этот файл, COMPATIBILITY.md
и README нужного модуля.

```text
Хочу настроить выбранные компоненты LG webOS Home Kit. Нужны:
[ ] быстрая оболочка Luma и удобный Home
[ ] приватность/реклама/предзагрузка на LG
[ ] клиент YouTube с блокировкой рекламы
[ ] доступ к YouTube без VPN через роутер
[ ] разобраться с Developer Mode и подходящим root для моего LG

Модель роутера: ...
Аппаратная ревизия: ... / пока неизвестна
Текущая прошивка и версия: ...
Есть ли уже root SSH: да / нет / неизвестно
Скорость тарифа: ...
Подключение для настройки: только Wi-Fi / доступен Ethernet
Для каких устройств нужен обход: ...
Модель LG: ...
Версия webOS: ...
Версия ПО/firmware LG: ...
Есть ли уже root SSH на ТВ: да / нет / неизвестно
Установлены ли Homebrew Channel / Developer Mode: ...
Желаемые приложения/HDMI для нового меню: ... / позже выберу сам

Сначала прочитай AGENTS.md, README.md, docs/COMPATIBILITY.md и документацию выбранных модулей.
Для LG также прочитай docs/LG_DEVELOPER_MODE.md, docs/LG_ROOT.md и docs/LG_TUNING.md.
Проверь в интернете первичные источники для ТОЧНОЙ модели/ревизии/прошивки:
производитель, OpenWrt Table of Hardware/Firmware Selector, bol-van/zapret2 и zapret.
Для LG проверь официальную документацию Developer Mode, webOS Brew и текущий upstream
конкретного root-метода/Luma. Версия webOS без версии ПО недостаточна для выбора эксплойта.
Приведи прямые ссылки. Не выводи совместимость из сходства названия или бренда.
Если доступа к источнику нет, отметь это как неизвестное.

Сначала ответь:
1. Совместима ли текущая прошивка; какие факты это подтверждают, чего не хватает.
2. Какой путь подходит: текущий OpenWrt, ручной порт под другую Linux-прошивку,
   отдельно согласованная смена прошивки, внешний шлюз или решение на устройстве.
3. Какие read-only команды нужны для уточнения, что из вывода можно безопасно передать.
4. Какие резервные копии, способы возврата и условия связи нужны перед изменениями.
5. Что реально автоматизирует эта репа и что придётся адаптировать отдельно.
6. Для LG: нужны ли root/Developer Mode, какой метод подходит по доказательствам,
   поддерживается ли только standalone Luma или также замена Home, какие настройки доступны.

На первом этапе только диагностика. Не прошивай роутер, не меняй WAN/Wi-Fi/firewall,
не запускай root, не включай WAN SSH и не запрашивай секреты. Мой дальнейший явный запрос на установку
позволит перейти к конкретным изменениям после проверки совместимости и отката.
Не запускай curl|sh и не используй бинарник другой архитектуры или модули чужого ядра.
Стратегии считай примерами: проверь их у моего провайдера и в пределах выбранных устройств.
Не обещай, что HTTP 200 доказывает видео, отсутствие рекламы или 4K.
Не удаляй LG Home, обязательные соглашения или системные службы ради обещанного ускорения.
Не выдавай отказ от ACR/голосовых согласий за физическое отключение микрофона.
```

## Если исходных данных мало

Сообщить только модель — нормальное начало. Нейросеть должна уточнить ревизию и прошивку
роутера либо версии webOS/ПО LG и предложить безопасную диагностику.
Название модели не даёт ей разрешения на прошивку или root.

Анкету также генерирует локальная команда:

```sh
python3 tools/assess_router.py --model "ТОЧНАЯ МОДЕЛЬ" --revision "РЕВИЗИЯ" --firmware "ПРОШИВКА"
```

Для уже собранных **обезличенных** фактов есть `--facts FILE`.
Формат показан в [router-facts.example.json](router-facts.example.json).
В нём нет поля для пароля, IP или ключа. Храните заполненную копию в `.local/`.
Утилита читает JSON и печатает анкету; она не подключается к устройству, не скачивает
прошивку и не подтверждает поддержку модели по базе данных.
